Metasurface Pixel Studio

1. Calibrate the physical display size

Measure the line below with a physical ruler and enter its measured length. After calibration, it should measure 50 mm. Measure again to check. Recalibrate after changing browser zoom, display scaling, or monitors.

2. Set the test conditions

Physical sample size is adjustable beside the image previews.


Import JPG, PNG or WebP, then adjust the pixel grid directly beside the comparison below.

Choose an image to convert it to an area-averaged pixel grid. Your image stays in your browser.

Every icon is constructed geometrically, then sampled on the same square pixel grid as the letters. Expressions use outlines and facial features; filled faces leave the eyes and mouth as background cutouts. Width and height control the icon independently. Features narrower than one test pixel may disappear.

A–Z and 0–9 use a built-in geometric stroke font; lowercase is converted to uppercase. Letter height includes the stroke width; character width follows the geometric font proportions. Sample width and height can be set independently without stretching the letters or square test pixels. Stroke width is specified in physical mm. Text is centered without automatic shrinking. Each square pixel is shown in full when its center lies inside the selected design; otherwise it is hidden. Cells crossing the sample boundary are omitted in letter mode. Letter outlines and effective stroke widths are quantized to the test pixel grid. The reference uses exactly the same selected cells filled with the average color of the underlying full-sample pattern.

Viewing distance is a calculation only: it changes the angular-size readout, not the physical pattern size. Move your eyes to the entered distance from the screen.


Approximate equal luminance is calculated using standard sRGB, not measured for your eyes or display. Compare black/white with red/green: can you detect texture, and can you distinguish the colors? Pixel color difference: 100% keeps the original colors; 0% makes both colors equal to the linear-light average.

3. Observe at 30, 40, and 50 cm

Measure distance from your eyes to the screen. The distance input only calculates angular size; it does not resize the pattern. Can you see texture? Can you distinguish the two colors? Does the pattern resemble the average color on the right? Press Esc or use the exit button to leave focus mode.

The default pattern is 10 mm wide, with 0.3 mm test pixels. Edge cells are clipped in full-sample mode; text, shapes and expressions use complete cells only. Display resolution limits accuracy: fewer than 3 display pixels per test pixel is a practical warning of coarse sampling, not a validated accuracy threshold. Area sampling reduces edge-rounding errors, but display subpixels and viewing angle can still affect results.

When using Imported image mode, edit the total width and height directly beside the enlarged previews. The image never stretches: the source aspect ratio is locked by default; when unlocked, Contain adds margins or Cover crops the edges. The left canvas shows your area-averaged pixel design and the right canvas shows the source image, both at the calibrated physical dimensions. The enlarged preview is not calibrated. This is an approximate test of visual spatial resolution. Display emission differs from the reflection, scattering, luminance, and spectrum of a real metasurface. It cannot precisely predict sample appearance. For a supplementary test with finer display sampling, scale sample size, test pixel size, and viewing distance by the same factor.
